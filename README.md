# 橙橙与甜甜 · 知识花园

面向 Bigme 电纸书的家庭学习网站。Windows 开发，GitHub Pages 发布，设备本地保存学习记录；家长导出 JSON 后，由 Codex 分析并更新内容。

## 第一版已有功能

- 两个孩子独立入口，各 8 张试学知识卡，共 48 道题。
- 今日知识卡、三道题、提示、一次重试、解释、难度与兴趣反馈。
- 知识地图、探索足迹、我的发现、家长观察与下次指定主题。
- IndexedDB 事务保存；按北京时间固定每日任务；任务携带完整内容快照。
- 无提示首次答对、提示后作答、首次错误和重试分别记录。
- 导出完整 JSON，校验并合并导入，避免重复计数。
- Service Worker 完整缓存；新版下载后手动切换，学习数据与内容缓存分离。
- 按视口高度一屏一页，知识卡分步展示，地图与长记录用底部按钮翻页；表单跨页保留输入，横竖屏切换重新排版。
- GitHub Pages 自动部署配置，使用相对资源路径与 hash 路由，支持仓库子路径。

试学内容根据设计稿编写，没有把示例中的学习表现当成真实基线。网站规则推荐可在本机运行；Codex 更新需要你提供导出记录，不会自行读取 Bigme。

## Windows 本地运行

需要 Node.js 20 或更新版本，不需要安装第三方依赖。

```powershell
npm run check
npm test
npm run dev
```

打开 `http://127.0.0.1:4173`。本地预览只监听本机；此地址不是 Bigme 的访问地址。

如果没有 npm，可直接使用 Node：

```powershell
node scripts/check.mjs
node --test tests/core.test.mjs
node scripts/serve.mjs
```

不要用文件管理器直接打开 index.html，模块和离线缓存需要通过 HTTP/HTTPS 服务。

## 发布到 GitHub Pages

1. 在 GitHub 创建仓库（例如 `knowledge-garden`），将项目推送到 `main` 分支。
2. 打开仓库 **Settings → Pages → Build and deployment → Source → GitHub Actions**。
3. 工作流检查内容和测试，通过后只发布 `site/` 目录。
4. 等待 Actions 成功，再用 Bigme 浏览器打开 Pages 返回的网址。
5. 等到页面提示离线内容已下载，再断网测试。可在支持的浏览器中添加到桌面。

仓库：<https://github.com/BetterCI/knowledge-garden>，目前为私有，尚未上线。GitHub 已返回“当前套餐不支持该仓库的 Pages”；自动检查仍会运行，部署会跳过。改为公开仓库后可启用 Pages；若升级到支持私有仓库 Pages 的套餐，可设置 Actions 变量 `ENABLE_PRIVATE_PAGES=true`。家庭学习记录不属于网站发布内容。

## 日常使用与 Codex 更新

1. Bigme 打开孩子入口，完成今日探索，选择难度和兴趣。
2. 家长入口导出 JSON 文件，将文件传到 Windows 的 `learning-records/` 目录（Git 忽略）。
3. 给 Codex 的指令示例：

   > 分析 learning-records/ 中最新的知识花园记录，结合家长观察，调整下一批学习内容。保留已有节点和题目编号；含义变化的题目请使用新编号，递增内容和缓存版本，运行检查和测试。

4. 可先运行 `node scripts/analyze-records.mjs "learning-records/文件.json"` 输出概览。
5. Codex 编辑 `site/content.js`；递增 `content.version` 和 `site/sw.js` 的 `CACHE_VERSION`（规则为 `garden-` 加内容版本，句点换成横线）。更新代码也需递增版本。
6. 提交并推送，Pages 自动发布。Bigme 家长入口检查更新，下载成功后切换新版。

内容更新保留 IndexedDB 数据。当天已生成的任务不被修改；新内容在下一次任务生成或打开知识卡时使用。保持节点 ID 稳定，才能接续学习历史；仅换题意时不要复用旧题目 ID。

## 推荐与掌握规则

- 未开始时，家长指定且满足前置证据的主题优先。
- 上次反馈“有点难 / 没看懂”时，安排一次回顾；文字观察由 Codex 解释。
- 之后优先未理解的其他概念、试学起点、可进入的新节点，再轮换回顾已有节点。
- 最近最多 6 次作答用于内部估计：独立答对 1，提示后答对 0.6，重试答对 0.75，错误 0。界面不显示精确掌握百分比。
- 至少 2 道不同题的证据且内部估计 ≥ 0.6，才能开放依赖此节点的每日任务。
- 内部估计 ≥ 0.8、3 道不同题独立答对、至少 2 个学习日期，才标记“已有掌握证据”。这是初步规则，不等于教育测评。
- 观看知识卡不提高掌握状态；每天一组核心任务，挑战入口共用这组任务。

## 数据与边界

学习数据按孩子隔离，保存在当前网址的当前浏览器。Windows 预览、GitHub Pages、不同浏览器、不同设备的数据不会自动互通；迁移通过导出/导入。家长入口是本机管理页，没有账号或访问控制。

JSON 包含作答与题目快照、学习反馈、家长观察及孩子的问题。不要放进公开仓库；`.gitignore` 已排除 `learning-records/`。清除浏览器存储、卸载浏览器或设备损坏会导致记录丢失，请定期备份。作答经过时长包含离开页面的时间，不代表专注学习时长。

新版保留旧资源缓存以避免多标签页资源版本混用；长期使用可通过浏览器管理缓存，但不要清除 IndexedDB 学习记录。离线启动、安装到桌面及下载行为仍需在具体 Bigme 型号和浏览器上实测。公开部署也需要在家庭网络检查访问情况。

第一版没有跨设备自动同步、在线 AI 调用、语音读题、手写识别和复杂排序/连线题。
